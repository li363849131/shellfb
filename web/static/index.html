💡 ShellFromBrowser 使用帮助 & 快捷键指南
⌨️ 常用快捷键 (Shortcuts)
粘贴文件 / 截图上传 Ctrl + V
从系统剪贴板直接粘贴图片或文件自动触发上传。
终端纯文本粘贴 Ctrl + Shift + V
将剪贴板文本原样粘贴到终端命令行中。
在线编辑器保存文件 Ctrl + S
文本编辑状态下静默保存文件回写服务器。
智能代码/补全采纳 Tab / Enter
出现 Cursor 风格灰色补全提示时采纳内容。
重命名窗口标签页 rename <名称>
在终端输入 setname 或 rename 重命名当前标签。
🚀 核心功能指南 (Features)
📁 文件传输与右侧浏览器
• 支持点击右上角 📷 上传/拖拽、拖拽本地文件到网页任意区域、或 Ctrl+V 粘贴上传。
• 上传进度实时显示在右侧文件浏览器面板顶部，支持大文件切片上传。
• 鼠标悬停文件行可点击 🗑️ 极速删除服务器文件。
📄 DOCX / XLSX / PDF / 文本 1:1 在线预览编辑
• Word (docx)：内置 docx-preview 原生 1:1 排版样式与字体解析。
• Excel (xlsx)：内置 SheetJS 自动生成底部工作表 Tab 选项卡预览。
• 文本编辑 (.txt/.py/.sh/.json/.md)：支持 1:1 像素级行号精确对齐、在线编辑与智能补全。
💻 Web VS Code IDE & 📁 Web 网盘快速入口
• 点击右上角 💻 VS Code：在独立标签页打开全功能远程 Web VS Code IDE（含完整插件市场与编辑器）。
• 点击右上角 📁 网盘：在独立标签页打开可视化文件管理器（FileBrowser）。
• 统一默认凭据：账号 admin / 密码 gjp。
🤖 三大命令行 AI 编程助手集成
• 输入 agy：唤起 Google Antigravity 智能 Agent。
• 输入 claude：唤起 Anthropic Claude Code Agent。
• 输入 codex：唤起 OpenAI Codex CLI 编程助手。
